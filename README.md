# Lethargic Gardens

Next.js storefront restored from the supplied project archive. The missing hero and collection images are supplied from the repository's existing garden photographs, and the merch image is generated. Images live in `public/images` at the paths already used by the app.

Run `npm install` and `npm run dev` with `DATABASE_URL` set to a PostgreSQL database. The Vercel project requires its existing database configuration and schema.
